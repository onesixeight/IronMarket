# Исправление DOCTYPE и контекста GA4 — 24 октября 2026

## Причины

Генератор HTML использовал `document.documentElement.outerHTML` для всех страниц, кроме конструктора. Этот метод возвращает элемент `<html>`, но не отдельный узел DOCTYPE. Поэтому опубликованные страницы открывались в режиме совместимости (`BackCompat`); PageSpeed независимо обнаружил отсутствие doctype.

Общий слой аналитики передавал место нажатия как `source` одновременно Google и Яндекс Метрике. GA4 показывал `desktop_header /` среди источников сеансов. Контекст интерфейса должен передаваться отдельно от источника привлечения.

## Изменения

- Все сохранённые HTML-документы начинаются с `<!doctype html>`. Особая очистка inline-стилей конструктора сохраняется.
- Адаптер GA4 переименовывает контекст `source` в `interaction_source` для всех событий, включая `catalog_open`, `contact_form_open`, `generate_lead` и `select_item`.
- Если новый параметр уже задан явно, он имеет приоритет. Исходный объект не изменяется, поэтому Метрика сохраняет прежний формат. Поля `campaign_source`, `campaign_medium` и UTM в адресе входа не переписываются.
- Правила согласия на cookies, имена событий, формы, тексты и CSS не меняются. Исторические данные GA4 этой правкой не пересчитываются.

## Проверки

До исправления воспроизведены падения проверки doctype опубликованного HTML и двух тестов отправляемых параметров Google.

Добавлены проверки:

- наличие doctype во всех 393 индексируемых HTML и проверяемых служебных документах при SEO-проверке сборки;
- стандартный режим `CSS1Compat` на прямых входах в главную, пагинацию, категорию, товар, конструктор, страницу благодарности и HTTP 404;
- отдельный контекст GA4, отсутствие `source` в Google-событии, неизменность параметров Метрики и сохранение UTM при реальных действиях в браузере с заглушками внешней аналитики;
- отсутствие событий до инициализации аналитики, неизменность исходного объекта, приоритет явного контекста и сохранение campaign-полей.

`interaction_source` собирается вместе с событиями. Для использования его в стандартных отчётах и исследованиях GA4 потребуется зарегистрированный пользовательский параметр уровня события; права доступа и настройки кабинета этой правкой не меняются. Документация: [параметры событий Google](https://developers.google.com/analytics/devguides/collection/ga4/event-parameters), [поля конфигурации](https://developers.google.com/analytics/devguides/collection/ga4/reference/config).

Локально прошли lint, все 223 модульные/регрессионные проверки, полная сборка 395 документов, 68 SEO-проверок, performance budgets и все 49 браузерных тестов. В тесте фильтрации дополнительно исправлено ожидание готовности Vue: статический HTML поля виден раньше подключения обработчика ввода.

Сравнение опубликованной и исправленной версии каталога и товара выполнено при 1280×900 и 390×844. Размеры и расположение основных блоков совпадают, горизонтального переполнения нет; у блока связанных товаров обнаружена разница положения на 1 px после переключения режима HTML. CSS и разметка компонентов не переписывались.

Для выпуска добавлен узкий override Miniflare на совместимую undici 7.30.1: изменена одна зависимость, версии Wrangler и Miniflare сохранены. Повторный audit: 0 уязвимостей.
